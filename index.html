Mis Proyectos Tecnológicos

🔒 Análisis de Ciberseguridad (CVE-41892)

Investigación y análisis exhaustivo de vulnerabilidades en un entorno de laboratorio controlado. El proyecto abarca el estudio teórico de la falla, la explotación práctica (pentesting) de la vulnerabilidad CVE-41892 y la posterior aplicación de parches y políticas para su correcta mitigación y resolución.

Pentesting CVE Analysis Mitigación

🌐 Arquitectura y Seguridad de Redes (UAH)

Diseño e implementación de una red completamente segura para un edificio de la Universidad de Alcalá de Henares. Utilizando Cisco Packet Tracer sobre los planos arquitectónicos reales, se aplicaron configuraciones avanzadas de routing, segmentación por VLANs, y estrictas políticas de seguridad (ACLs).

Cisco Packet Tracer VLANs / ACLs

🛒 Desarrollo E-commerce Real (BM Pozuelo)

Proyecto web corporativo para un club deportivo de la 1ª División Española. Abarca todo el ciclo de vida del software: reuniones iniciales de captación de requisitos con el cliente, diseño de la interfaz (UI/UX) y actual fase de implementación técnica para la gestión de productos y socios.

Desarrollo Web Ingeniería de Requisitos

🚲 Sist. Distribuidos (Alquiler Bicicletas)

GitHub 🔗

Arquitectura distribuida para una plataforma de alquiler web. Integra una pasarela de pago funcional, simulador interactivo de tráfico en tiempo real y, lo más importante, validación segura de tokens de sesión para proteger las cuentas de los usuarios y las transacciones.

Web Architecture Tokens / Seguridad

🧠 Machine Learning (NLP y Text Mining)

GitHub 🔗

Desarrollo de algoritmos de inteligencia artificial aplicados al Procesamiento de Lenguaje Natural (NLP). Se implementó un clasificador de texto multilingüe y modelos avanzados de modelado de temas (BERTopic) para la inferencia, agrupación y análisis de enormes volúmenes de texto.

Python NLP / BERTopic

GitHub 🔗

Aplicación de escritorio completamente responsive programada en C# bajo la plataforma Universal Windows Platform (UWP). Fuerte enfoque en el diseño de interfaces UI/UX usando pautas de Fluent Design. Incorpora un minijuego de combate por turnos, animaciones fluidas y notificaciones nativas del SO.

C# UWP / Fluent Design

🔄 Compresor y Conversor Multimedia

GitHub 🔗

Plataforma web potente para la gestión y manipulación masiva de archivos. Además, el sistema genera dinámicamente reportes en PDF con las estadísticas de conversión.

File Processing PDF Generation
